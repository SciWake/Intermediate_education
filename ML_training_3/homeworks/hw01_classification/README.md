### Условие:

Решите задачу **Warmup (hw_fmnist)** из репозитория в папке:

```
homeworks/hw01_classification
```

После решения задачи классификации выполните следующие шаги:

1. **Сгенерируйте посылку** и загрузите в данную задачу файл:
   ```
   submission_dict_mnist_task_1.json
   ```

2. Для этого файл:
   ```
   hw**_data_dict.json
   ```
   из папки с задачей **должен находиться в той же директории, что и ноутбук**.

3. Скрипт для автоматической загрузки доступен в ноутбуке.  
   При возникновении ошибок — попробуйте **скачать файл вручную**.

---

### Важно:

- Вердикт **ОК** означает лишь то, что код **запустился**.  
- **Корректность выполнения** задания оценивается **баллами**.

### Проверка:

- Полученные **баллы** и результаты прохождения **тестов** можно увидеть по ссылке на **"отчет" о посылке**.
